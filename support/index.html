Windows display scaling#

If the workspace does not fill your screen, or looks smaller than expected, set Settings → System → Display → Scale & layout to 100% and restart the application. Higher scale values reduce the logical pixel area available to the app.

Common issues#

Samples show as missing after moving a project

Projects reference their samples by path. Move the project folder as a whole, or use the relink prompt to point at the folder containing the audio. The manual's troubleshooting section covers the relink flow.

A backing track will not import

Check the file against the format table above. Long or very large files, and codecs your system does not provide, are the usual causes.

Audio device still busy after closing

Some Windows audio stacks hold the device briefly after the app exits. Wait a few seconds before relaunching or before starting another audio application.

Exporting an arrangement takes as long as the song

That is expected. EXPORT ARRANGEMENT is a real-time bounce — the arrangement is played and recorded rather than rendered offline, so it takes about as long as the song lasts. Leave it running until it reports completion.

Performance

Latency and voice count depend on your hardware and audio stack, so results vary between machines. A dedicated low-latency interface makes the largest difference.
